# docs/archive — historical only

Everything in this folder is **kept for history and context, not as current truth.** It can
be stale. If anything here disagrees with `../../START-HERE.md` or the current docs in
`docs/publishing`, `docs/roadmap`, `docs/vision`, or `docs/reviews`, those win.

- **`handoffs/`** — one-off chat handoff notes written to pass context between sessions
  (CHAT-HANDOFF, PITCH-HANDOFF, CONSOLIDATED-HANDOFF, etc.). Superseded by the
  `SESSION-LOG.md` + `START-HERE.md` chain. Going forward, use the chain instead of new
  handoff files.
- **`superseded/`** — earlier plans/status files replaced by the current docs
  (old PUBLISH-PLAN / PUBLISH-STEPS / PUBLISH-CHECKLIST, the messaging setup plan, the old
  STATUS.md, the parked seven-spirit-levels idea, old design notes).
- **`old-screenshots/`** — early web-preview renders.

Nothing here was deleted in the v1 cleanup; it was moved out of the root so the current
docs are easy to find.
