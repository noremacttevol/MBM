# CHANNEL-PLAN — one presence, four platforms

Cameron creates the accounts (they need his phone/passwords). Everything else is
prepared here so each platform takes about 5 minutes. Do them in this order:
**YouTube → Instagram → TikTok → Facebook** (YouTube first because the Google
account anchors the rest; Facebook last because it can reuse the Instagram login
for cross-posting).

---

## 1. The name and handle — decide ONCE, use everywhere

- **Public name (all platforms):** `Milk Before Meat`
- **Handle, in order of preference:**
  1. `@milkb4meat` ← **recommended** — matches the domain milkb4meat.org, short, easy to say out loud
  2. `@milkbeforemeat`
  3. `@mbm.stories`

**Before creating anything:** check the #1 handle on all four platforms (just try
it in each signup screen, or search it). Use the highest option on the list that is
free on **all four**. The whole point is that someone who sees a video on TikTok can
find the same name on YouTube. Never mix (e.g., `@milkb4meat` on two platforms and
`@milkbeforemeat` on the other two).

## 2. Shared identity assets (already in the repo)

- **Profile picture (all four):** `Marketing-Launch-Kit/page-art/profile_1080.png`
- **Facebook cover:** `Marketing-Launch-Kit/page-art/cover_facebook_1640x624.png`
- **YouTube banner / TikTok:** none needed at launch — skip, don't stall on art.
- **The link (all four bios):** `https://milkb4meat.org` — one link, covers both stores.

## 3. Account hygiene (2 minutes, once)

- Create/use one email you control for all four (your Gmail works; you can move to
  admin@milkb4meat.org later — changing email later is easy, changing handle is not).
- Turn on two-factor authentication on each account the day you create it.
- **Nothing here costs money.** No verification badges, no paid tools, no boosts at
  launch. If a signup screen asks for payment, you're on the wrong screen.

## 4. Platform setup — 5 minutes each

### YouTube (Shorts)
1. youtube.com → sign in → profile picture → **Create a channel** → name it
   `Milk Before Meat` (this makes a channel, separate from your personal identity).
2. Set the **handle** (Settings → Channel → Basic info) to the chosen handle.
3. Upload the profile picture.
4. **Description** — paste:
   > Short scripture stories, told word-for-word from the King James Bible — realistic
   > pictures, one narrator, no music, no noise. One story, one verse, one honest
   > question. From the Milk Before Meat app: https://milkb4meat.org
5. Add links (Customization → Links): `https://milkb4meat.org` and the App Store page
   `https://apps.apple.com/us/app/milk-before-meat/id6783621048`.
6. Post video #1 from `POST-QUEUE.md` (upload the mp4 from `social/exports/`, paste
   title + caption; a vertical video ≤3 min automatically becomes a Short).

### Instagram (Reels)
1. Create the account with your email → username = the chosen handle → name
   `Milk Before Meat`.
2. Switch to a **Creator** account (Settings → Account type and tools → Switch to
   professional account → Creator → category "Personal blog" — skip any prompt to
   connect ads or payment).
3. Profile picture + **bio** (150-char limit) — paste:
   > Scripture stories, word for word from the KJV. One story, one verse, one honest
   > question. From the Milk Before Meat app ↓
4. Add the website link: `https://milkb4meat.org`.
5. Post video #1 as a **Reel** (paste caption + hashtags from the queue, set the
   cover from `social/covers/`), then open it → ⋯ → **Pin to profile**.

### TikTok
1. Create the account → username = the chosen handle → display name `Milk Before Meat`.
2. Switch to a **Business account** (Settings → Account → Switch to Business account →
   category "Media & Entertainment"). This is free and unlocks the clickable website
   field — personal accounts need 1,000 followers before they can add a link.
3. Profile picture + **bio** (80-char limit) — paste:
   > Scripture stories, word for word from the KJV. From the Milk Before Meat app ↓
4. Add the website: `https://milkb4meat.org`.
5. Post video #1 (upload via tiktok.com on the computer — the files are on this
   machine and the web uploader lets you pick the cover frame and schedule).

### Facebook (Page + Reels)
1. facebook.com → Menu → Pages → **Create new Page**.
2. Name `Milk Before Meat`, category **App page** (or "Religious organization" if
   App page isn't offered).
3. Profile picture + cover photo (`cover_facebook_1640x624.png`).
4. **Bio** — paste:
   > Short scripture stories, told word-for-word from the King James Bible — realistic
   > pictures, one narrator, no music, no pressure. One story, one verse, one honest
   > question at a time. Watch a few here, or get the app and let them come to you one
   > story at a time: https://milkb4meat.org
5. Set the Page username to the chosen handle (Page settings → Username), add the
   website field and an action button → **Learn more** → `https://milkb4meat.org`.
6. Post video #1 as a **Reel** from the Page (not your personal profile), pin it.

## 5. Profile framing — what these pages are and aren't

- The pages present the **stories**, not the church, not an argument. Milk only.
- The app is named plainly in every bio and caption — never hidden, never pushed.
- No affiliation claims: MBM is Cameron's independent app; the pages never imply the
  videos are official Church media.
- The person behind the page is reachable: keep DMs open on all four platforms.
  (Message requests from strangers land in a "Requests" folder — check it when you
  do your daily replies.)
