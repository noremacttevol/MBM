# Peter Walks on Water — Complete Codex Test

This is one complete visual-direction test for Story 07. It does not alter the
app, published feed, existing Story 07 builds, narration, caption text, or
timing.

## Deliverable

`video-build/peter-walks-on-water-codex-test-v5.mp4`

The video contains 18 distinct Codex-directed story pictures used across 26
timed picture slots, plus the existing closing card.

V4 is retained only as the visual-test history. It is rejected as a finished
cut because its special build folder contained a shortened audio copy. V5 reads
the authoritative Story 7 text and timing in place and stream-copies the
authoritative final AAC audio without re-encoding it.

## Supporting material

- `PROMPTS.md` — final shared direction and all 18 shot prompts
- `QC.md` — source-picture, rendered-shot, and technical verification
- `assets-source/` — accepted generated PNG sources
- `video-build/assets-v4/` — normalized build pictures

## Resolution note

The built-in image-generation workflow produced accepted sources at
approximately 921×1707 or 941×1672. They were resized with Lanczos filtering for
the 1536×2752 build canvas, and the delivered video is 1080×1920. This is a
complete prompt and visual-direction test, but the still sources are not native
2K Flow exports.
